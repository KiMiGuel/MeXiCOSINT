Qué hace

Un número entra. Un expediente sale.

MeXiCOSINT toma cualquier número telefónico mexicano y genera un análisis completo: validación, operadora, tipo de línea, localidad IFT/LADA, evidencia entre fuentes, enlaces de investigación y reporte exportable.

EXCLUSIVO
🏛️

Base oficial IFT/PNN offline

177,996 bloques de numeración asignada del Plan Nacional de Numeración, dentro del paquete. Operadora, modalidad y fecha de asignación — directo del regulador, sin conexión.

✅

Validación completa

Formato nacional e internacional (E.164), región por phonenumbers, referencia LADA y parsing local de números mexicanos.

🗳️

Estados de evidencia

IFT/PNN y LADA definen la localidad canónica; AbstractAPI, NumVerify, Google Places e IPQualityScore agregan apoyo o conflicto — sin falsas certezas.

🚨

Detección de números premium

Series 200/300/500/800/900 identificadas automáticamente. Los números 900 (sobre cuota) disparan alerta roja de posible estafa.

🔗

Enlaces de investigación

Links OSINT verificados: WhatsApp por wa.me y búsquedas Google con variantes exactas del número, incluyendo Facebook, TikTok, X y Twitter.

📁

Reportes exportables

Reporte JSON con hash SHA-256 y mapa HTML de la localidad canónica IFT/LADA. Listo para documentar investigaciones.

Lo que la hace única

La única herramienta con la base oficial del IFT

Ninguna otra herramienta OSINT consulta el registro del regulador mexicano. MeXiCOSINT lo lleva integrado: sin internet, sin APIs, sin costo por consulta.

  • Operadora oficial — el concesionario dueño del bloque (Telcel, Telmex, AT&T, Movistar y 20+ más)
  • Modalidad — línea fija, móvil (CPP/MPP) o no geográfico
  • Fecha de asignación — cuándo el IFT asignó el bloque
  • Actualizable — tools/update_ift_blocks.py descarga el plan vigente

Llaves API

Potencia MeXiCOSINT al 100% con llaves API

La base oficial del IFT y la validación local funcionan sin configurar nada. Con llaves API opcionales, MeXiCOSINT agrega validación, reputación, fichas públicas de negocio y geocodificación de la localidad IFT/LADA. Esa localidad no es GPS ni ubicación del suscriptor.

AbstractAPI — Validación de teléfonos

TELÉFONOS GRATIS

Qué hace: valida y enriquece números telefónicos: validez, formato, país, operadora, tipo de línea y señales de apoyo.

Cómo se integra: AbstractAPI aporta evidencia telefónica opcional. No reemplaza la fuente oficial IFT/LADA.

Nivel gratuito disponible

Guía de registro:

  1. Abre el enlace de registro de AbstractAPI.
  2. Crea una cuenta y entra al panel de Phone Validation.
  3. Copia tu API key.
  4. Regresa a tu terminal y guárdala en MeXiCOSINT:
# guardar la llave una sola vez mexicosint --set-key abstract TU_KEY

Listo. A partir de ese momento, cada escaneo incluye la evidencia de AbstractAPI cuando el proveedor responda.

Crear cuenta gratis en AbstractAPI

NumVerify — Validación global de números

TELÉFONOS GRATIS

Qué hace: valida números de 232 países contra los registros de numeración internacionales: validez, formato local e internacional, operadora, tipo de línea y país.

Cómo se integra: NumVerify aporta validación secundaria y evidencia de apoyo o conflicto. No reemplaza la localidad concreta de IFT/LADA.

Nivel gratuito: 100 validaciones / mes

Guía de registro (el sitio está en inglés — así lo haces):

  1. Abre el enlace de registro — cae directo en el plan "Free" (0 USD, sin tarjeta).
  2. Llena el formulario: nombre en "Full Name", correo en "Email" y contraseña en "Password".
  3. Pulsa "Sign Up". NumVerify crea tu cuenta al instante, sin confirmación de correo.
  4. Entra a tu panel ("Dashboard"): tu llave aparece arriba como "Your API Access Key". Cópiala.
  5. Regresa a tu terminal y guárdala en MeXiCOSINT:
# guardar la llave una sola vez mexicosint --set-key numverify TU_KEY

Listo. NumVerify se usará automáticamente cuando su key exista.

Crear cuenta gratis en NumVerify

OpenCage — Geocodificación primaria

MAPAS OPCIONAL

Qué hace: geocodifica la consulta canónica IFT/LADA con formato ciudad, estado, Mexico.

Importante: solo se geocodifican localidades concretas. Valores vagos como país, región o etiquetas genéricas se omiten.

mexicosint --set-key opencage TU_KEY

Geoapify — Geocodificación fallback

MAPAS OPCIONAL

Qué hace: convierte la localidad canónica IFT/LADA en coordenadas aproximadas para mapas cuando OpenCage no está disponible o no devuelve resultado.

Importante: esto representa la localidad de numeración, no la ubicación en vivo del teléfono ni del suscriptor.

Guía de registro:

  1. Abre el registro de Geoapify y crea una cuenta.
  2. Entra a tus proyectos y crea o selecciona un proyecto.
  3. Copia la API key del proyecto.
  4. Regresa a tu terminal y guárdala en MeXiCOSINT:
mexicosint --set-key geoapify TU_API_KEY
Crear cuenta en Geoapify

Google Places — Fichas públicas de negocio

NEGOCIOS OPCIONAL

Qué hace: busca posibles fichas públicas asociadas al número E.164 normalizado y normaliza nombre, categoría, dirección pública, sitio web, Maps URL y place ID.

Importante: una posible ficha pública no identifica al suscriptor.

Guía de registro:

  1. Abre Google Cloud Console.
  2. Inicia sesión con una cuenta de Google.
  3. Crea o selecciona un proyecto.
  4. Activa la facturación para ese proyecto.
  5. Abre "APIs & Services".
  6. Habilita "Places API (New)".
  7. Abre "Credentials".
  8. Crea una API key.
  9. Restringe la key a Places API.
  10. Regresa a tu terminal y guárdala en MeXiCOSINT:
mexicosint --set-key google_places TU_API_KEY
Abrir Google Cloud Console

IPQualityScore — Reputación telefónica

RIESGO OPCIONAL

Qué hace: agrega evidencia normalizada de validez, actividad, riesgo, abuso reciente, VoIP, operadora y tipo de línea.

Guía de registro:

  1. Abre la página de registro de IPQualityScore.
  2. Crea una cuenta.
  3. Verifica el correo si el sitio lo solicita.
  4. Abre el panel de tu cuenta.
  5. Localiza y copia la API key privada.
  6. Regresa a tu terminal y guárdala en MeXiCOSINT:
mexicosint --set-key ipqualityscore TU_API_KEY
Registrarse en IPQualityScore
